# GraphVis 18.4 for Windows

## Install

Double-click **`Install.exe`**.

That is it — no Rust, Python, CMake, or command line setup is required.

If Windows does not launch the EXE normally, double-click **`Install.bat`** as a fallback.

## After installation

Launch **GraphVis** from the Start Menu or Desktop shortcut.

Need repair? Open the `Support` folder and use `Repair.bat`. To remove GraphVis completely, double-click the root-level `Uninstall.bat`. It removes installed files, GraphVis settings/cache, shortcuts, and registry entries, then removes the extracted release folder. It leaves the original downloaded ZIP untouched.
